# Deliver BOOKS

Private development workspace for the Deliver BOOKS Egypt storefront and admin.

## Current state
- Customer storefront foundation follows the Center El Gowaily visual system.
- Commerce and order-security concepts are adapted from Aquarium Cafe.
- Supabase project is dedicated to this site.
- Delivery pricing/zones are intentionally NOT configured until the business owner confirms them.
- No Vercel project or deployment is configured by this repository.

## Local development
Use any static HTTP server and open `index.html`.

## Important
Never place Supabase service-role keys in browser code.
